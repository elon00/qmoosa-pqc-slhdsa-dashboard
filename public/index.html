Underlying Mathematical Architecture

SLH-DSA combines three layered cryptographic primitives:

  • WOTS+ (Winternitz One-Time Signatures): Base-16 hash chains authenticate individual leaf keys without secret key reuse vulnerabilities.
  • FORS (Forest of Random Subsets): Few-time signature scheme signing message digests across multiple parallel random trees.
  • XMSS Hypertree: Multi-layer Merkle trees forming a root public key anchor with ADRS address domain separation.
